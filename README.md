# SPEngine

(теперь пишу без нейронки)
Фреймворк движок для разработки игр на Sony PlayStation 1 с использованием C++ версии 12.3.0
Модули:
<br> Render
<br> Geometry
<br> Parser
<br> Storage
<br> Sound
<br> Pad
<br> Fx
<br> Registry

## ПРО ДВИЖОК

### Распределение оперативной памяти
Движок сам по себе забирает оперативную память, потому ниже разбор сколько место занято и сколько остаётся разработчику для сцен:
* **Принцип сколько надо**: Все массивы написаны статичными - 512 объектов в реестре, 256 файлов звука, 64 файлов в хранилище. Сделано это с учётом того, что разработчик сам, зная сколько примерно максимум может быть объектов, изменит эти самые значения прям в движке.
* **Память ядра** (СТАРАЯ ИНФОРМАЦИЯ): В чистой конфигурации движок потребляет всего 154 002 байта (~150 КБ) RAM, отдавая весь остальной объем под нужды разработчика. В эти числа входят:
В эти числа входят:
<br> **.text** 17 852 байта (~17.4 КБ)
<br> **.data** 66 байт
<br> **.bss** 136 084 байта (~132.8 КБ) или 37 972 байт (~37 КБ) если брать минимальный размер массивов
<br> стандартная конфигурация с тестовыми сценами занимает примерно **648КБ**.

### СЦЕНЫ
Вся логика разработчика пишется в сценах. Физика, объекты, управление всё пишется в сценах. Сцена это класс который наследуется от общего класса Scene и живёт как обычный объект, не смотря на то что все модули это статичные классы

### СБОРКА
Почти автономная. Первичная настройка это:
* Установка PSn00bSDK как `C:\psnoobsdk`
* В папке проекта прописать cmake --preset default
<br>Далее для сборки проекта прописывается команда cmake --build build
